# Restaurant Profitability Analytics
## Run locally
1. Install Python 3.10 or newer.
2. In this folder, run `pip install -r requirements.txt`.
3. Run `streamlit run app.py`.
4. Open the local URL shown in the terminal.
## Files
- `app.py`: interactive dashboard
- `restaurant_sales_costs.csv`: synthetic dataset (900 rows)
- `PROJECT_REPORT.md`: full project report
- `RESEARCH_PAPER_DRAFT.md`: paper draft (not published/approved)
- `FEEDBACK_VIDEO_SCRIPT.md`: video script
## Data note
All rows are synthetic demonstration data, not actual restaurant transactions.
## Deploy
Push this folder's contents to a GitHub repository, then create a Streamlit Community Cloud app using `app.py` as the entry point. Keep `app.py`, CSV and `requirements.txt` in the repository root.
