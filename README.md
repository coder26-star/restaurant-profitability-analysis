# Restaurant Profitability Analysis

An interactive data analytics project focused on understanding restaurant cost structures and channel-wise profitability using Python and Streamlit.

## Live Dashboard

**Explore the application:** [Restaurant Profitability Analysis](https://restaurant-profitability-analysis-ylfywshsnucs4tvwwhufsg.streamlit.app/)

## Project Overview

Restaurants need to understand how their costs relate to revenue and how profitability varies across sales channels. This project demonstrates how structured sales and cost data can be explored through an interactive dashboard.

The goal is to support data-driven analysis of restaurant profitability and make financial information easier to explore and understand.

## Objectives

* Explore restaurant sales and cost data.
* Examine cost structure and profitability.
* Compare performance across sales channels.
* Present analytical information through an interactive dashboard.
* Demonstrate practical Python-based data analytics skills.

## Technology Stack

* **Python** — data analysis and application logic
* **Stream lit** — interactive web dashboard
* **CSV** — dataset storage

## Run Locally

1. Install Python 3.10 or newer.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the application:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL displayed in your terminal.

## Dataset Disclaimer

This project uses **synthetic demonstration data**, not actual restaurant transactions. Any insights or results generated from the dataset are illustrative and should not be interpreted as verified findings about real restaurants.
